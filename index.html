01 · The Problem

Local AI is powerful.
It's also chained to a desk.

ComfyUI is the most capable open source generation tool there is, and it asks for your whole desk in return. Every tweak, every reroll, every "one more seed" means sitting in front of the node graph.

Cloud services solve mobility by renting you compute you already own. The missing piece was never more GPU. It was a remote: something personal and instant that lets the machine at home do the work while you live your life.

The remote tools that already existed took the universal approach, dumping every node parameter into raw unsorted lists. Technically complete, practically unusable with thumbs.

The design problem wasn't exposing controls. It was deciding which ones deserve your screen, in what order, and making the rest available without letting them win.

02 · The Solution

One file. Every workflow.
Designed for thumbs.

Return Current runs in any mobile browser. No app store, no install, no server-side code. Feed it a workflow PNG straight from your outputs folder, or a workflow JSON, and every editable parameter is auto-detected and sorted into an order that matches how you actually work: model, seed, prompt, sampler, then a compact row for the numbers you rarely touch. LoRAs stack at the bottom. Anything exotic folds into an Advanced drawer instead of cluttering the screen.

03 · What It Does

Built for thumbs, not menus.

▤

Smart workflow editor

Import a PNG or JSON and the fields sort themselves. Seed comes with a lock toggle for A/B testing. Custom nodes the app has never seen still show up, tucked under Advanced with full parameter access.

▣

Living gallery

Results stream in and slide into place, grouped by date. Same-prompt runs stack into albums you can fan open. Videos preview themselves as they pass the center of your screen.

∞

Iterate from anywhere

Every output carries its full workflow in the metadata. The ∞ button reloads it with the seed preserved, so comparing a LoRA swap or a prompt tweak takes two taps, not a trip to your desk.

✦

Seven themes, one glow

A single accent cascades through every surface: progress shimmer, carousel indicator, queue pulse, overlay glyphs. The Legendary theme runs an animated holographic foil gradient, the kind of thing that makes you want to generate one more just to watch it.

◈

LoRA command center

Toggles, strength you can type past the slider's range, dropdowns organized by folder with your current model's family on top, and trigger words you enter once and keep forever. One tap copies the active set.

▶

Video native

Wan 2.2 image-to-video with the Lightning setup ready in the example workflow. Frame interpolation for smoother motion is one toggle, and the app rewires the graph for you on submit. Outputs loop in the lightbox; hold an edge to auto-pan a set.

04 · Design Language

Darkroom chassis, safelight glow.

The visual system borrows from a photographic darkroom: near-black surfaces with one luminous accent doing all the talking. Two typefaces play against each other. A bold italic display voice handles identity moments like model names, gallery dates, and the running job. A utilitarian mono handles every technical field. The contrast tells you instantly what's information and what's control.

05 · Process

Built in conversation.
Shipped in iterations.

The entire app came together through rapid sessions with Claude: describe a behavior, test it on a real phone against a live ComfyUI server, report what broke or felt wrong, refine. Over sixty archived builds document the evolution. Every animation timing, glow intensity, and touch target was tuned against real fingers on real hardware.

Phase · Foundation

Connection and workflow engine

WebSocket link to ComfyUI, PNG metadata extraction, and the auto-detection system that turns any workflow graph into an editable mobile form.

Phase · Reliability

Bulletproofing the pipeline

Mobile browsers kill background connections. Missed-generation sync, auto-reconnect, and persistent state tracking made the gallery trustworthy. Lock your phone mid-render, come back, everything's there.

Phase · Delight

Making it feel good to use

Shimmer progress with live ETA, slide-in gallery animations, long-press auto-pan with a pulsing charge indicator, seven glowing themes. Speed stayed sacred; every effect got tested for snappiness and cut if it slowed a tap.

Phase · Depth

Power features

Video pipelines with one-tap frame interpolation, Ideogram color palettes with native hex pickers, seed locking, LoRA trigger memory, JSON import with full graph conversion, and the universal Advanced section.

Phase · Release

Beta hardening

Errors that name the failing node so a fix takes one report, example workflows for five model families, and setup docs written for people who already know their way around ComfyUI.

06 · Point of View

No subscription, no upload queue, no waiting on someone else's servers. Your PC renders. The current returns.

07 · Try It

Free. Open. Yours.

Return Current is free, open source, and one file you can read top to bottom. Development continues in public, with beta testers surfacing new node types and workflows to support.

Supported by donations, not subscriptions. The tool answers to its users, not a pricing page.

The repo includes five example workflows (SDXL, Anima, Ideogram 4, Krea 2, and Wan 2.2 video) that share a demo chain: the image workflows each render their model name as a glass emblem in a surrealist garden, and the video workflow's default prompt animates whatever they produce.
