01 · The Problem

Local AI is powerful.
It's also chained to a desk.

ComfyUI is the most capable open-source image and video generation tool available — but it demands you sit at your PC, staring at a node graph, for every single generation.

Cloud services solved mobility by charging monthly rent for compute you already own. The missing piece wasn't more compute or another subscription — it was a remote control. Something with the immediacy of a Walkman: personal, portable, instant.

Existing remote tools exposed every node parameter in raw, unsorted lists — technically universal, practically unusable on a phone.

02 · The Solution

One file. Every workflow.
Designed for thumbs.

A complete ComfyUI companion that runs in any mobile browser — no app store, no install, no server-side code. Drop a workflow PNG or JSON on it and every editable parameter is auto-detected, intelligently sorted, and styled for one-handed use.

04 · Design Language

Darkroom chassis, safelight glow.

The visual system borrows from a photographic darkroom: near-black surfaces, one luminous accent doing all the talking. Two typefaces play against each other — a bold-italic display voice for identity moments (model names, dates, the running job) and a utilitarian mono for every technical field. The contrast tells you instantly what's information and what's control.

05 · Process

Built in conversation.
Shipped in iterations.

The entire app was developed through rapid iterative sessions with Claude — describe a behavior, test it on a real phone against a live ComfyUI server, report what broke or felt wrong, refine. Over 30 archived builds document the evolution. Every design call — animation timing, glow intensity, touch-target sizes — was tuned against real fingers on real hardware, not mockups.

Phase — Foundation

Connection & workflow engine

WebSocket link to ComfyUI, PNG metadata extraction, and the KNOWN_KEYS auto-detection system that turns any workflow graph into an editable mobile form.

Phase — Reliability

Bulletproofing the pipeline

Mobile browsers kill background WebSockets. Missed-generation sync, auto-reconnect, and persistent state tracking made the gallery trustworthy — lock your phone mid-render, come back, everything's there.

Phase — Delight

The dopamine layer

Shimmer progress bars with live ETA, slide-in gallery animations, long-press auto-pan with a pulsing charge indicator, seven glowing themes. Speed stayed sacred — every effect was tested for snappiness and cut if it slowed a tap.

Phase — Depth

Power features

Video pipelines with RIFE toggle, Ideogram color palettes with native hex pickers, seed locking, LoRA trigger memory, JSON import with UI-to-API graph conversion, and a universal Advanced section for any custom node.

Phase — Release

Beta hardening

Privacy-scrubbed builds, error surfaces that name the failing node, setup documentation, and distribution prep for the ComfyUI creator community.

06 · Point of View

The magic isn't in the cloud — it's in the machine you already own. This is the remote control for it: fast enough to feel like flicking a lighter, considered enough to use professionally.

07 · Outcomes

Free. Open. Yours.

Released as free, open-source software for the ComfyUI community — one file anyone can inspect, fork, or carry on a USB stick. Development continues in public, with beta testers surfacing new node types and workflows to support.
